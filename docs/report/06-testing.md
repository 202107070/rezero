## 6.2 결함 수정 보고서 (개발 후반 주요 건)

| 결함 | 증상 | 원인 요약 | 조치 |
|------|------|-----------|------|
| 힌트 정보 없음 | `(정보 없음)` | 라이브 문제에 클라 정답 부재 | 서버 effect로 힌트 전달 |
| 빌드+ 오활성 | 빌드 없는 문제에 컬러 | code 스타일만 보고 활성 | `isCodeBlankBuildProblem` 게이트 |
| 낙서 불가 | 아이템 소모만 됨 | Strict Mode/`started` 게이트 | 캔버스 항상 기동 |
| 결과 이탈 미반영 | 흑백·알림 없음 | presence 디바운스·USER_LEFT 미처리 | 이탈 감지·시드 보강 |
| 풀이 시간 오류 | 남은 시간처럼 표시 | 시계 기준 혼동 | 게임 경과 기준 기록 |
| AI 0% | 맞은 문제 있는데 0% | 재채점·캐시 | problemResults 우선·캐시 무효화 |
| 전체화면 작음 | UI 밀도 과소 | 확대 없이 stretch만 | `--ui-scale` transform |

================================================================================
 data-dictionary.txt — 프론트엔드 데이터·변수 사전
================================================================================

UI·화면 흐름은 front.txt 를 본다. 이 문서는 백엔드·협업용으로
프론트에 쓰이는 **변수·타입·저장 위치**를 정리한다.

  ※ API 스펙이 아님. 현재는 메모리 store 기준이며, DB/API 연동 시
    store 내부가 서버 데이터로 교체될 예정.

  범례 [저장]
    UI     … 해당 페이지 React state (앱 실행 중, 페이지 벗어나면 해제)
    STORE  … userService / sessionStore / roomStore 등 (앱 실행 중 유지)
    URL    … 라우트 쿼리 문자열 (새로고침·공유 시 전달)
    CONST  … constants / problems.js (정적)
    —      … UI 전용 (백엔드 연동 대상 아님, 참고만)

================================================================================
 H. 문제 capabilities · visual 자산
================================================================================

  [원칙]
    문제 JSON: type, visual, capabilityOverrides 만 저장
    UI·배틀 로직: resolveProblemCapabilities() 결과(currentCaps)만 참조

  [동작 방식]  (플래그처럼 쓰지만 JSON에 직접 저장하지 않음)
    problems.js 에 hasVisual·canUseHint 같은 boolean 을 문제마다 박아 두지 않는다.
    저장 필드는 type, visual, capabilityOverrides(선택) 뿐이다.

    현재 문제가 바뀔 때마다 아래 파이프라인으로 currentCaps 를 계산한다.

      type + visual + capabilityOverrides + gameMode
              ↓
      resolveProblemCapabilities()     … problemCapabilities.ts
              ↓
      currentCaps (ProblemCapabilities)   … boolean 플래그 묶음

    BattlePage·PracticeProblemViewer 는 currentCaps 만 보고 UI·아이템을 분기한다.
      패널 표시     showCodePanel | showMultipleChoicePanel | showShortAnswerPanel
      보기 렌더     hasVisual || hasImage
      아이템 사용   canUseItem(currentCaps, itemKey)  →  items[itemKey] true/false
      힌트·빌드+    canUseHint, canUseBuildBonus (items 에서 파생)

    capabilityOverrides 가 있으면 STYLE_ITEM_POLICY 를 해당 문제만 일부 덮어쓴다.
    gameMode === 'normal' 이면 items 전 필드를 false 로 만든 뒤 위 플래그에 반영된다.

  [스타일 → type 매핑]
    code              ← fill_blank, visual_fill_blank
    short_answer      ← short_answer
    multiple_choice   ← multiple_choice

  [아이템 정책 — item 모드, STYLE_ITEM_POLICY]
    code            revealLength, revealPrev, blankBreak, buildCharge + 공격 전부
    short_answer    revealLength, revealPrev + 공격 전부 (blankBreak·buildCharge 불가)
    multiple_choice 자기 버프 전부 불가, 공격 아이템만 허용
    normal 모드     items 전 필드 false

  [visual 렌더]
    shouldRenderVisual = hasVisual || hasImage
    hasImage = visual.kind === 'image' && imageFile 존재
    image 경로: ./assets/problem-images/{imageFile}
    html/css/ascii/svg/canvas — previewHtml·previewCss·content 인라인 (problems.js)

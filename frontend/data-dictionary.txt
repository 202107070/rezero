================================================================================
 data-dictionary.txt — 프론트엔드 데이터·변수 사전
================================================================================

UI·화면 흐름은 front.txt 를 본다. 이 문서는 백엔드·협업용으로
프론트에 쓰이는 **변수·타입·저장 위치**를 정리한다.

  ※ API 스펙이 아님. 현재는 메모리 store 기준이며, DB/API 연동 시
    store 내부가 서버 데이터로 교체될 예정.

  범례 [저장]
    UI     … 해당 페이지 React state (앱 실행 중, 페이지 벗어나면 해제)
    STORE  … userService / sessionStore / roomStore 등 (앱 실행 중 유지)
    URL    … 라우트 쿼리 문자열 (새로고침·공유 시 전달)
    CONST  … constants / problems.js (정적)
    —      … UI 전용 (백엔드 연동 대상 아님, 참고만)
